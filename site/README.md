# ReplyLoom website

This directory contains the bilingual static product website and privacy
policy, including public screenshots and the introduction video.

- `index.html`: product page
- `privacy.html`: privacy policy
- `app.js`: interface translations
- `styles.css`: page styles
- `assets/`: public media

Website: https://iruochen.github.io/replyloom-site/
